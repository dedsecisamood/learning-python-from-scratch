# Stage 1: Foundations

Start with output, variables, values, arithmetic, and keyboard input.

## Concepts in this stage

`print()`, variables, `str`, `int`, `float`, `bool`, `None`, arithmetic, `input()`, and type conversion.

## Read and run in this order

| Order | File | What I am practicing | Try or observe |
| --- | --- | --- | --- |
| 1 | [helloworld.py](helloworld.py) | Print my first greeting. | Run it and change the greeting. |
| 2 | [datatype.py](datatype.py) | Store values with different types. | Uncomment the `type()` print calls to inspect each value; the current script prints nothing. |
| 3 | [variable2prac.py](variable2prac.py) | Calculate with variables. | It currently subtracts 9 - 8 but labels the result `a+b`; correct that label as a follow-up. |
| 4 | [operators.py](operators.py) | Placeholder for operator practice. | This file is empty. Add examples of arithmetic and comparison operators when revisiting it. |
| 5 | [input.py](input.py) | Read a name and build a greeting. | Enter `Siam` at the prompt. |
| 6 | [excersice1.py](excersice1.py) | Combine stored variables with user input. | Enter a code name such as `Iron Man`. |
| 7 | [prac1.py](prac1.py) | Convert two inputs to floats and average them. | Enter `4.5`, then `7.5`; the average should be `6.0`. |

## Run an example

From the repository root:

```powershell
python lessons/01-foundations/helloworld.py
```

Run each file separately. Enter values when a prompt appears. Predict the output, run it, and then change one value to understand the result.

## Reflection prompts

- What did the program do, and which line caused that behavior?
- What changed when I used another input or value?
- What question or improvement should I record in my [journal](../../docs/LEARNING_JOURNAL.md)?
