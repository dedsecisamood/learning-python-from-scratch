# Stage 2: Strings

Work with text one character, slice, and method at a time.

## Concepts in this stage

string literals, newline escapes, concatenation, `len()`, zero-based indexing, slicing, and string methods.

## Read and run in this order

| Order | File | What I am practicing | Try or observe |
| --- | --- | --- | --- |
| 1 | [strings.py](strings.py) | Create, join, and measure strings. | Predict the length of the joined name before running. |
| 2 | [indexing.py](indexing.py) | Read one character by its index. | The first character is at index 0. |
| 3 | [slicing.py](slicing.py) | Extract text using positive and negative slices. | Compare `[:4]`, `[5:]`, and `[-3:-1]`; the stop index is excluded. |
| 4 | [string_functions.py](string_functions.py) | Try common string methods. | Observe `endswith()`, `capitalize()`, `replace()`, `find()`, and `count()`. |
| 5 | [prac2.py](prac2.py) | Count occurrences of a character. | Count the dollar signs manually, then compare with `.count()`. |

## Run an example

From the repository root:

```powershell
python lessons/02-strings/strings.py
```

Run each file separately. Enter values when a prompt appears. Predict the output, run it, and then change one value to understand the result.
