# Stage 3: Decisions

Choose an outcome with conditions and connect comparisons with logic.

## Concepts in this stage

indentation, comparisons, `if` / `elif` / `else`, `and`, and the remainder operator `%`.

## Read and run in this order

| Order | File | What I am practicing | Try or observe |
| --- | --- | --- | --- |
| 1 | [conditionals.py](conditionals.py) | Use an age threshold with if/else. | Change the example age to 17 and then 18. Treat the eligibility text as a toy example. |
| 2 | [conditionals2.py](conditionals2.py) | Select a traffic-light branch. | Try `red`, `yellow`, and `green`; other values also reach the current else branch. |
| 3 | [gradesystem.py](gradesystem.py) | Convert marks to a grade. | Enter `85` to select grade B. Marks outside 0-100 are not rejected yet. |
| 4 | [prac3.py](prac3.py) | Check whether an integer is even or odd. | Try `8`, then `7`. |
| 5 | [prac4.py](prac4.py) | Find the greatest of three inputs. | Try `8`, `3`, `5`; then investigate ties. |
| 6 | [prac5.py](prac5.py) | Check divisibility by seven. | Try `49`, then `50`. |
| 7 | [prac6.py](prac6.py) | Combine divisibility conditions. | Try `21`, `9`, `14`, and `10` to cover the branches. `Wrong` means neither divisor matched. |
| 8 | [prac7.py](prac7.py) | Find the greatest of four inputs. | Try `2`, `9`, `5`, `7`; then investigate ties. |

## Run an example

From the repository root:

```powershell
python lessons/03-decisions/conditionals.py
```

Run each file separately. Enter values when a prompt appears. Predict the output, run it, and then change one value to understand the result.
