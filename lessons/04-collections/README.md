# Stage 4: Collections

Group related values with dictionaries and sets, including nested data.

## Concepts in this stage

dictionary keys and values, updates, nested dictionaries, list and tuple values, sets, uniqueness, union, and intersection.

## Read and run in this order

| Order | File | What I am practicing | Try or observe |
| --- | --- | --- | --- |
| 1 | [Dictonary.py](Dictonary.py) | Create, read, and update a dictionary. | Inspect the name, age, subject list, and marks tuple. |
| 2 | [nested_dict.py](nested_dict.py) | Read a dictionary inside another dictionary. | Compare the whole student record with its `subs` value. |
| 3 | [dict_methods.py](dict_methods.py) | Inspect dictionary length, keys, and values. | Observe the different views and conversions. |
| 4 | [dict_m2.py](dict_m2.py) | Use get(), items(), and update(). | Compare the name before and after the update. |
| 5 | [sets.py](sets.py) | Create an empty set. | Notice that `set()` creates a set; `{}` creates a dictionary. |
| 6 | [set_methods.py](set_methods.py) | Combine sets with union and intersection. | Predict the unique elements and common elements; printed ordering may vary. |
| 7 | [prac_10.py](prac_10.py) | Store word meanings in a dictionary. | The two adjacent strings for `table` form one string; revisit their representation. |
| 8 | [prac11.py](prac11.py) | Count unique subjects using a set. | The current result is 5. A trailing space in `Python ` is part of the value. |
| 9 | [prac12.py](prac12.py) | Build a subject-marks dictionary from input. | Enter `85`, `90`, and `80`; inspect the resulting mapping. |
| 10 | [prac13.py](prac13.py) | Explore numeric equality inside a set. | `9 == 9.0` is true, so these values occupy one set entry. |

## Run an example

From the repository root:

```powershell
python lessons/04-collections/Dictonary.py
```

Run each file separately. Enter values when a prompt appears. Predict the output, run it, and then change one value to understand the result.
